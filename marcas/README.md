# Marcas

O índice canônico é [registro.json](registro.json). Cada pasta tem marca_id, canais e fontes próprios.

- [Xamã Pena Azul do Amor](xama-pena-azul-do-amor/README.md): Cortes Energéticos e Chamado da Alma Gêmea.
- [Seres Multidimensionais](seres-multidimensionais/README.md): sete carrosséis existentes preservados.

Para acrescentar outra marca, preparar tarefa com nome, marca_id, handle e URL de cada canal conhecido, identidade e responsáveis. Destinos desconhecidos ficam pendentes. O integrador atualiza o registro após revisão.

Adaptação entre marcas exige copy, identidade, CTA e aprovação próprios. Trocar o @ não transfere aprovação.
